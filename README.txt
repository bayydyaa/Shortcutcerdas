SHORTCUT CERDAS — PETUNJUK SINGKAT

SEBELUM UPLOAD
Buka app.js, cek bagian DEFAULTS paling atas. Pastikan 4 alamat web kamu
(Pasar Tani Cerdas, Pertanian Cerdas, Kasir Cerdas, Kamera Cerdas) sudah benar.
Daftar ini muncul otomatis saat dashboard pertama kali dibuka di HP/tablet/laptop.

UPLOAD KE GITHUB PAGES
1. Buat repository baru (Public), misalnya: shortcutcerdas
2. Upload SEMUA file di folder ini ke root repository (jangan di dalam subfolder)
3. Settings > Pages > Deploy from a branch > main / (root) > Save
4. Tunggu 1-2 menit, buka URL yang muncul

PASANG DI HP
- iPhone (Safari): Share > Add to Home Screen (dibuka di Safari, bukan layar penuh)
- Android / tablet (Brave/Chrome): Menu (⋮) > Add to Home screen / Install app

CARA PAKAI
- Tambah: tekan "+ Tambah", tempel alamat web, Simpan. Nama boleh dikosongkan.
- Logo: dicari otomatis dari web-nya. Kalau web tidak punya logo, muncul huruf awal berwarna.
- Edit / Hapus: tekan tombol ••• di pojok kartu.
- Logo belum muncul / salah: buka Edit, langsung tekan Simpan, logo dicek ulang.

PENTING
- Shortcut disimpan di browser masing-masing perangkat, tidak sinkron otomatis.
  Pindah perangkat: Cadangkan di perangkat lama, Pulihkan di perangkat baru.
- iPhone: versi Home Screen dan versi Safari punya data terpisah. Pakai salah satu saja.
- Setelah update file di GitHub, tutup lalu buka lagi dashboard-nya untuk versi terbaru.
